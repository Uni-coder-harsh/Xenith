# Benchmark Results Directory

This directory stores benchmark output reports (JSON, CSV, Markdown tables) generated by the XENITH Benchmark Runner.

---

## 📊 Standard Output Metrics

Benchmark output files record:
- Instance Name
- Number of Variables ($n$), Constraints ($m$), Non-zeros ($\text{nnz}$)
- Solver Status (`OPTIMAL`, `INFEASIBLE`, `UNBOUNDED`, etc.)
- Objective Value ($c^T x^*$)
- Reference Objective Value Error
- Primal Feasibility Violation ($\|A x - s\|_{\infty}$)
- Dual Feasibility Violation
- Total Simplex Iteration Count
- LU Refactorization Count
- Solve Wall-Clock Time (ms)
- Peak Heap Usage (MB)

*Result files are generated locally during benchmark runs and excluded from git tracking.*
